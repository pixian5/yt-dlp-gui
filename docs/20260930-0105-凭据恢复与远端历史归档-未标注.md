# gh 凭据恢复与远端历史归档

操作时间：2026-09-30 01:05（Asia/Singapore）

## 凭据问题与恢复

此前 `gh auth status` 报 `The token in keyring is invalid.`，导致无法创建/推送远端仓库。复查发现 **`gh` 本身已经恢复正常**：`gh auth status` 显示 `✓ Logged in to github.com account pixian5 (keyring)`，作用域 `gist`、`read:org`、`repo`、`workflow`，`gh api user` 返回 `pixian5`。这属于 keyring 凭据的瞬时读取失败，不是账号或 token 被吊销。

若以后再遇到同类问题，按顺序排查：

1. `gh auth status`：只看 `github.com` 段落是否出现 `✓ Logged in`。
2. `gh api user --jq .login`：真正验证 token 能否访问 API，比 `auth status` 更可靠。
3. token 确实失效时再 `gh auth refresh -h github.com -s repo,workflow`，或在网页生成 PAT 后 `gh auth login --with-token`（不要把 token 写进仓库或提交）。
4. Git 凭据与 gh 相互独立：本项目 `git push` 走 `osxkeychain` helper，gh 走 keyring 中的 `gho_` token，任一方失效不影响另一方。
