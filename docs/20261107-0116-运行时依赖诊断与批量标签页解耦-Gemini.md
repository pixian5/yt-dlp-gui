# 运行时依赖诊断与批量标签页解耦架构重构

## 1. 概述与背景

在前面的版本中，我们完成了 `guiapi` 基础模块（`command_builder`, `runner`, `config_store`, `tab_builders`）的建立与 16 个常规设置标签页的拆分。为了进一步提升桌面应用在多种宿主环境下的鲁棒性，本轮迭代完成了两大核心目标：
1. **环境与核心多模态探测及运行时健康自检**；
2. **批量下载（Batch Download）与播放列表（Playlist Select）交互代码全量模块化下沉**。

版本正式升至 **`0.1.4`**。

---

## 2. 核心架构改进

### 2.1 多模态核心启动与系统回退机制 (`guiapi/core.py`)
- **`find_core_checkout() -> Path | None`**：温和探测同级 `yt-dlp` 仓库或 `YT_DLP_CORE_DIR`，找不到时返回 `None` 而不抛出异常阻断启动流程。
- **`core_launcher() -> list[str]`** 形成 5 级优雅降级策略：
  1. PyInstaller 冻结环境：直接调用同级独立可执行文件 `yt-dlp-cli`；
  2. 显式环境变量 `YT_DLP_EXECUTABLE`：允许用户/脚本强制指定已编译二进制路径；
  3. 源码检出目录（同级仓库或 `YT_DLP_CORE_DIR`）：调用当前 Python 解释器 `sys.executable -m yt_dlp` 并注入 `PYTHONPATH`；
  4. 系统环境已安装的二进制：通过 `shutil.which('yt-dlp')` 自动适配全局安装的 CLI；
  5. 最终安全回退到当前环境模块调用。
- **`probe_core_info()`**：提取当前核心版本号（如 `2026.01.01`）、运行模式（`frozen` / `executable` / `source` / `system`）及位置，在主窗口启动时以标题栏及日志反馈给用户。
- **`sanitize_command()`**：增强测试断言，确保 `--password`, `--video-password`, `--token`, `--proxy` 等敏感认证信息在展示和落盘时严格脱敏。

### 2.2 工具链健康探测 (`guiapi/runner.py`)
- **`check_runtime_dependencies()`**：
  - 自动检测 `ffmpeg`, `ffprobe`, `node`, `deno` 等外部依赖；
  - 提取并规范化各工具的版本字符串（如 ffmpeg version, node version）；
  - 将探测状态结构化返回给 GUI 层。

### 2.3 启动异步诊断 (`guiapi/app.py`)
- 在 `YtDlpGUI.__init__` 中以守护线程异步执行 `_run_startup_diagnostics()`：
  - 探测到 yt-dlp 核心版本后，自动更新主窗口标题（例如 `yt-dlp GUI (2026.01.01) - ...`）；
  - 打印已就绪的工具链状态：`[INFO] Runtime tools: ffmpeg (6.1.1), node (v20.10.0)`；
  - 缺失 `ffmpeg` 时输出醒目警告 `[WARNING] ffmpeg not found in PATH! Merging audio/video or postprocessing may fail.`；
  - 缺失 JS 引擎时输出提醒 `[NOTICE] No JS runtime (node/deno) detected...`。

### 2.4 批量下载与播放列表模块化解耦 (`guiapi/tab_builders.py`)
- 将 `create_batch_download_tab` 与 `create_playlist_tab` 及共 30 个复杂交互方法全量迁移至 `tab_builders.py`：
  - 批量 URL 动态列表拖拽排序（`_on_drag_start`, `_on_drag_motion`, `_on_drag_stop`, `_swap_rows`）；
  - 剪贴板提取与上下追加（`_extract_urls_from_clipboard`, `paste_bulk_to_top`, `paste_bulk_to_bottom`）；
  - 批量串行预检与标题异步拉取（`parse_all_bulk_urls`, `_fetch_playlist_title_async`）；
  - 播放列表树状多选与反选（`_on_tree_click`, `_on_tree_space`, `_on_playlist_select_all`）。
- `guiapi/app.py` 的代码行数由 **3,038 行精简至 2,521 行**（相比初始重构前的 4,882 行已减少近半），大幅降低了维护心智负担。
